
# CLAUDE.md — WordCards (застосунок для вивчення англійських слів)

## Про проєкт
Особистий застосунок для iPhone для вивчення англійських слів картками.
Це **PWA** (вебзастосунок, який встановлюється на iPhone через Safari → «На початковий екран»).
App Store, Xcode і Mac не використовуються. Розробка ведеться на **Windows**.
Користувачі: автор і кілька друзів. Кожен користується окремо, без акаунтів і без сервера.

## Мова спілкування
- Відповідай мені **українською**. Коментарі в коді та назви змінних — англійською.
- Перед великою зміною коротко опиши план (3–7 пунктів), потім виконуй.
- Після кожного етапу: що зроблено, як перевірити, які файли змінено.

## Технічний стек (не змінювати без погодження)
- Vite + Vue 3 (Composition API, `<script setup>`) + TypeScript
- Pinia — стан; vue-router у режимі **hash** (`createWebHashHistory`) — щоб працювало на GitHub Pages
- vue-i18n — інтерфейс українською та англійською
- Dexie (IndexedDB) — усі дані користувача зберігаються лише на телефоні
- vite-plugin-pwa (Workbox) — маніфест, офлайн, оновлення з підказкою (`registerType: 'prompt'`)
- Шрифт Nunito через `@fontsource/nunito` (локально, щоб працювало офлайн)
- Без важких UI-бібліотек і бібліотек графіків: графіки — власні прості SVG-компоненти
- Анімації — CSS transform/transition, без сторонніх бібліотек жестів (Pointer Events)
- Хостинг: GitHub Pages через GitHub Actions. `base` у vite.config = `'/<назва-репозиторію>/'`

## Формат бази слів (`public/words/<level>.json`)
Масив об'єктів:
```json
{
  "id": "go-verb",
  "word": "go",
  "forms": ["go", "went", "gone"],
  "ipa": "/ɡəʊ/",
  "pos": "verb",
  "level": "A1",
  "category": "travel",
  "translation": ["йти", "їхати"],
  "synonyms": ["leave", "travel"],
  "example": "We go to the sea every summer.",
  "exampleUk": "Ми їздимо на море щоліта."
}
```
- `id` = `<слово-через-дефіс>-<pos>`, унікальний **у всій базі** (не лише в одному файлі).
- `forms` — лише для неправильних дієслів (рівно 3 форми), інакше `null`.
- `ipa` — британська транскрипція у слешах.
- `translation` — 1–3 варіанти українською, найуживаніший перший.
- `synonyms` — 0–3 англійські синоніми (можна порожній масив).
- `example` — просте природне речення рівня слова (не складніше за рівень), 5–12 слів.
- Категорії (`category`): `home, nature, travel, food, work, health, city, feelings, tech, shopping, sport, family, clothes, communication`.
  Режим «Мікс» — це не категорія в базі, а вибір усіх категорій.
- Рівні CEFR визначаються орієнтовно (за частотністю та загальноприйнятими списками). Не копіювати дослівно сторонні захищені списки — формувати власну базу.
- Після будь-якої зміни бази запускати `npm run words:check`.

## Дані користувача (Dexie)
- `progress` — ключ `wordId`; поля: `status: 'learned' | 'review'`, `level`, `category`,
  знімок слова (`word`, `forms`, `translation`), `firstSeenAt`, `updatedAt`, `timesKnown`, `timesUnknown`, `lastCheckedAt`.
- `activity` — ключ `date` (`YYYY-MM-DD`, **локальна** дата); поля: `answered`, `known`, `unknown`, `newLearned`.
- `settings` — ключ/значення.
- `badges` — `id`, `earnedAt`.
- При першому запуску викликати `navigator.storage.persist()`.

## Правила навчання (бізнес-логіка)
1. Користувач обирає **рівень** (A1–C2) і **категорію** (або «Мікс») на головному екрані й натискає «Почати».
2. Розмір сесії — з налаштувань: 10 / 20 / 30 (за замовчуванням 20).
3. Набір формується «непомітно»: застосунок завантажує `words/<level>.json` (кешується service worker'ом) і обирає слова.
4. **Слова не повторюються**: нові слова — лише ті, яких немає в `progress`.
5. **Підмішування повторення**: ~25% сесії (округлення вниз, для 20 → 5) — слова зі статусом `review`
   (пріоритет: та сама категорія і рівень → той самий рівень → будь-які). Якщо таких мало — решта нові слова.
   Слова повторення на картці позначаються міткою «Повторення». Порядок карток перемішаний.
6. «Знаю» → слово летить **вправо**, статус `learned`. «Не знаю» → летить **вліво**, статус `review`.
   Слово з повторення + «Знаю» → переходить до `learned`.
7. Керування: кнопки «Знаю» / «Не знаю» **і** свайп вправо/вліво (поріг ~100 px, картка нахиляється, з'являється штамп ЗНАЮ / НЕ ЗНАЮ).
   Тап по картці (без перетягування) — переворот. Кнопка динаміка не перевертає картку.
8. Кнопка «Завершити» → **одразу на головний екран**. Відповіді, дані до цього моменту, зберігаються; слова без відповіді лишаються «новими».
9. Після останньої картки → **екран підсумку** (знаю / не знаю / серія / ціль дня) → кнопка «На головну».
10. **Перевірка вивчених**: якщо вивчених ≥ 20 і з останньої перевірки минуло ≥ 7 днів (або перевірки ще не було),
    на головному екрані з'являється банер «Перевірте вивчені слова». Сесія перевірки містить лише `learned`
    (найдавніше перевірені першими). «Знаю» → оновити `lastCheckedAt`; «Не знаю» → статус `review`. «Пізніше» відкладає банер на 2 дні.
11. Якщо нових слів у категорії не вистачає — показати екран «Нові слова в цій категорії закінчилися» з пропозицією обрати іншу категорію/рівень або пройти лише наявні.
12. **Серія днів**: день зараховується, якщо дано хоча б одну відповідь. Рахувати за локальною датою телефона. Зберігати поточну й рекордну серію.
13. **Денна ціль**: кількість відповідей за день (10/20/30/50, за замовчуванням 20).

## Картка
- Лицьова сторона: слово (для неправильних дієслів — усі три форми `go – went – gone`), транскрипція IPA, кнопка динаміка, речення-приклад.
  Більше нічого (без частини мови, без рівня).
- Зворотна сторона: переклад (1–3 варіанти), переклад речення-прикладу, синоніми (якщо є) дрібним шрифтом.
- Анімація перевороту — 3D flip (`rotateY`, `backface-visibility: hidden`).

## Вимова
- Web Speech API (`speechSynthesis`), без інтернету й без ключів.
- Мова `en-US` або `en-GB` з налаштувань; швидкість: звичайна / повільна (0.75).
- Голоси на iOS завантажуються асинхронно — чекати подію `voiceschanged`. Озвучування запускати лише з обробника натискання.

## Статистика
Кількість вивчених; кількість на повторенні; поточна серія; рекордна серія; кільце денної цілі;
графік активності (тиждень / місяць, перемикач); календар активності (теплокарта ~20 тижнів);
розподіл за рівнями та категоріями; бейджі досягнень; перехід до списків слів.
Бейджі: перша сесія; 10/50/100/250/500/1000 вивчених; серії 3/7/14/30/100 днів; перша перевірка вивчених.

## Екран «Мої слова»
Вкладки «Вивчені» / «На повторенні», пошук, у кожного рядка кнопка ручного переміщення в інший список.

## Налаштування
Мова інтерфейсу (Українська / English); розмір сесії (10/20/30); денна ціль (10/20/30/50);
вимова (US/UK); швидкість вимови; «Про застосунок» (версія, кількість слів у базі).
Сповіщень **немає**. Тема — **автоматично** за налаштуваннями iPhone (`prefers-color-scheme`).

## Дизайн
- Яскравий «ігровий» стиль: великі заокруглення (20–28 px), насичені кольори, м'які тіні, жирний Nunito.
- Палітра: основний фіолетовий `#6C4CF1`, «Знаю» зелений `#22C55E`, «Не знаю» кораловий `#F43F5E`,
  акцент жовтий `#FACC15`, фон світлої теми `#F5F3FF`, темної `#14112B`. Усі кольори — через CSS-змінні.
- Мобільний макет під iPhone: `viewport-fit=cover`, відступи `env(safe-area-inset-*)`,
  нижня панель вкладок: Навчання · Статистика · Слова · Налаштування.
- Кнопки не менше 44×44 pt. Контраст тексту AA.
- Без зайвих анімацій під час читання; рух — лише переворот, політ картки, кільця прогресу.

## PWA
- Маніфест: `name: "WordCards"`, `display: "standalone"`, `theme_color`, `background_color`, іконки 192/512 + maskable,
  `apple-touch-icon` 180×180 у `index.html`.
- Офлайн: застосунок і файли `words/*.json` кешуються (Workbox). Після першого відкриття працює без інтернету.
- Оновлення: при новій версії — ненав'язливий банер «Доступна нова версія → Оновити».

## Команди
- `npm run dev -- --host` — запуск для перевірки з iPhone у тій самій Wi-Fi мережі
- `npm run build` — збірка; `npm run preview` — перегляд збірки
- `npm run words:check` — перевірка бази слів
- `npm run test` — юніт-тести (Vitest) логіки вибору слів, серій і бейджів

## Правила роботи
- Працюй малими кроками, після кожного етапу проєкт має запускатися без помилок (`npm run build`).
- Логіку (вибір слів, серії, бейджі) покривай тестами Vitest.
- Не додавай сервер, акаунти, аналітику, рекламу, сторонні трекери.
- Не зберігай ключів API в коді.
- Після кожного етапу роби git-коміт з коротким описом українською.
- Якщо вимога з цього файлу суперечить моєму промпту — запитай, а не вгадуй.
